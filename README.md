# Portable File Share

Advanced portable file sharing server using:

- Flask
- Cloudflare Tunnel
- QR Code Sharing
- Mobile Friendly UI
- Upload & Download
- ZIP Download
- Linux Support
- ARM/AMD64 Support

## Features

- Cloudflare public URL
- QR code generation
- Multi-file upload
- Download all ZIP
- Mobile support
- LAN access
- Dark UI
- Fast setup
